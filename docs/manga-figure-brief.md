# 依頼書：手描き漫画文庫の人物（顔と体）の描き方を良くする

このファイルは、ほかの AI に人物の描き方の改善を頼むときに、そのまま渡すための依頼書です。
**このファイルと一緒に、下の「渡すファイル」も添付してください。**

---

## 1. 何を作っているか

小説を読み進めると、いま読んでいる場面が 1 ページの漫画（2〜4 コマ）になる Web ページです。
コマの中の人物は、画像ではなく **canvas に毎コマ手描き風の線で描いています**（`manga/draw.js` の `person()`）。
今回お願いしたいのは、この人物の **顔と体の描き方の改善** です。

## 2. 渡すファイル

| ファイル | 中身 | 変えてよいか |
|---|---|---|
| `manga/draw.js` | 背景・人物・動物の描き方。人物は `person()` から下 | **人物の部分だけ変えてよい** |
| `manga/tegaki.js` | 手描き風の線を引く小さなライブラリ（図形を少しずつ揺らす） | 変えない（使い方の参考） |
| `manga/preview.html` | 部品の見本ページ。人物の種類・姿勢・表情・時代を選んで確かめられる | 確かめるのに使う |
| `プレビューアーの人物の描き方.md` | 手の形・表情・向き・見え方の決まり（持ち主の別のツールの資料） | 参考 |
| 今の絵のスクリーンショット | 見本ページの「人物の一覧」の画面など | 参考 |

## 3. 守ってほしいこと（変えると壊れるもの）

- **体の寸法（プロポーション）は変えない。** `dims(type, h)` が決める頭の大きさ・肩幅・腰の高さ・手足の太さはそのまま。頭は大きめ、目は顔の中心より下
- **線の太さ：** 人物の線はすべて眉と同じ太さ（`browW(d)`）。顔の部品（目・口など）は `faceBase` の中の太さ
- **乱数を使わない。** `Math.random` は使わず、`seed` と時刻 `t` だけで決める（同じ場面・同じ時刻なら同じ絵になる）。新しい部品には、ほかと重ならない `seed` の番号を振る
- **線は `tegaki.js` の関数で引く**（`tg.shape` `tg.ellipse` `tg.rrect` `tg.poly` `tg.line` `tg.limb`）。canvas の `ctx` を直接使ってよいのは、影や半透明の塗りくらい
- **関数の入口は変えない：** `Draw.person(tg, L, o, t)` の `o` は `{ type, era, pose, expr, x, y, h, facing, slot, variant, shade, seat, gesture, view, talking, alpha }`。値を足すのはよいが、今ある値の意味は変えない
- **座標：** 足もとが原点、上が −y。右向き（+x が顔の前）で描き、左向きは呼ぶ側で左右反転（`facing: -1`）
- **描けなければならない組み合わせ（全部エラーなく描けること）：**
  - 種類 13：成人男性・成人女性・少年・少女・老人（男）・老人（女）・中年男性・中年女性・幼児・兵士/騎士・僧侶/聖職者・おばけ・不明
  - 時代 4：近代日本・現代日本・西洋風・ファンタジー（服装が変わる。表 `COSTUME`）
  - 姿勢 12：立つ・座る（正座／椅子）・歩く・走る・横たわる・話す・しゃがむ・手を振る・泣く・抱き合う・剣を振る・拳を突き出す
  - 表情 9：ふつう・喜び・落ち着き・悲しみ・不安・怒り・驚き・泣く・眠る
  - 手の形 8：両手を上げる・手を振る・指す・考える・覆う・腰に手・のけぞる・持つ
  - 向き：正面寄り（少し振り向き）・後ろ姿（`view: 'back'`）・横顔（`view: 'side'`）
  - 2 人目が同じ種類のときの「パターン B」（髪型と服の色違い）
- **重さ：** 1 秒に 8 回描き直すので、人物 1 人の図形の数を今の 1.5 倍以上に増やさない

## 4. 良くしてほしいところ（例。優先順に）

1. **共通の部品をそろえる**
   - 手・靴・首・衿もとなど、何度も出る部品を 1 つの関数にまとめ、種類・時代・向きで同じ描き方を使う
   - 正面・後ろ姿・横顔で、同じ部品（耳・髪・衿）の形と位置がずれないようにする
2. **服の描き方**
   - 着物：衿の重なり（右前）、帯、袖の袂（たもと）の垂れ方。座る・歩くときの裾の形
   - 洋服：シャツの衿・袖口、スカートの広がり、コートの前合わせ、鎧の継ぎ目
   - しわは少なく、線の数より形で見せる（漫画の簡単な絵柄）
3. **顔**
   - 表情ごとに眉・目・口の組み合わせがはっきり違って見えるように（特に 不安／悲しみ、怒り／驚き）
   - 横顔・後ろ頭の髪型を、正面の髪型（短髪・分け目・おかっぱ・長い髪・お団子・おさげ・ポニーテール・坊主）と同じ人に見えるように
4. **姿勢**
   - 座る・しゃがむ・歩くときの腰と膝の位置を自然に（寸法は変えずに関節の位置だけ）

## 5. 出してほしいもの

- `manga/draw.js` の **変更点だけ**（差分、または差し替える関数をまるごと）
- 変えたところの説明を 5〜10 行で。「何が・どう良くなるか」を、見た目の言葉で
- 新しく足した値（例：服の種類）があれば、その一覧
- 一度に全部ではなく、**4 の 1 つの項目ずつ** 出してもらえると確かめやすい
