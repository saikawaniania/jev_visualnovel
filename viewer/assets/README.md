# 素材ライブラリ

> **ライセンス**：ここにある画像（`bg/`・`sil/`）は、リポジトリの MIT ライセンスの対象外です。再配布・転用はしないでください。
> 素材の作り方は `PROMPTS.md` を参考にしてください。

ここに置いた絵が `manifest.json` 経由で読み込まれ、該当する組み合わせだけ仮素材と差し替わります。
足りない組み合わせは仮素材（場所名入りのグラデーション・図形のシルエット）のまま動きます。

## 置き方

1. 下の規則どおりの名前で `bg/` と `sil/` に置く
2. `node viewer/tools/build-manifest.mjs` を実行して `manifest.json` を作り直す（手で書いてもよい）。
   Netlify ではデプロイのたびに自動で実行されるので、画像を GitHub にアップロードするだけでよい
3. ビューアをローカルサーバー経由で開き直す（`file://` では manifest を読めないため仮素材のみ）

画像生成AIで作るときのプロンプト例と典型的な場面の一覧は `PROMPTS.md` にあります。

## ファイル名

| 種類 | 名前 | 例 |
| --- | --- | --- |
| 背景 | `bg/bg_{era}_{location}_{time}.webp` | `bg/bg_modern_washitsu_day.webp` |
| シルエット | `sil/sil_{figure}_{pose}.jpg`（白地に黒。透過 PNG も可） | `sil/sil_woman_sit.jpg` |
| 群衆 | `sil/crowd_*.jpg`（白地に黒。透過 PNG も可・3人以上用） | `sil/crowd_1.jpg` |

- era：`modern`（近代日本）・`present`（現代日本）・`western`（西洋風）・`fantasy`（ファンタジー）
- location：`washitsu` 和室・`yoshitsu` 洋室・`kitchen` 台所・`genkan` 廊下・玄関・`classroom` 教室・`shop` 店・酒場・`station` 駅・車内・`street` 街路・`alley` 路地・`garden` 庭・`field` 田畑・野原・`forest` 森・山道・`river` 川・水辺・`seaside` 海辺・`nightsky` 夜空の見える屋外
- time：`morning` 朝・`day` 昼・`evening` 夕方・`night` 夜
- figure：`man` 成人男性・`woman` 成人女性・`boy` 少年・`girl` 少女・`old` 老人・`unknown` 不明
- pose：`stand` 立っている・`sit` 座っている・`walk` 歩く・走る・`lie` 倒れる・横たわる・`talk` 向き合って話す

## 探す順番

背景は「その時代・場所・時間帯の絵」→「その時代・場所の昼の絵＋色調レイヤー」→（`fallbackEra` の時代で同じ順）→ 仮素材。
夜・夕方の絵がなくても、昼の絵に色調レイヤーを重ねて代用します。時間帯専用の絵のときは色調を弱めます。

## 素材の仕様

- 背景：人物なし、低彩度、輪郭をややぼかす。白文字が上に乗っても読める明度に揃える。1:1（スマホ中心なら 3:4）で、端が切れても成立するよう大事なものは中央に。シルエットは 1:1 で全枚統一、群衆は 16:9
- シルエット：白地に黒一色の JPG（ビューアが読み込み時に白地を透明にする）か、黒一色の透過 PNG。足元を画像の下端に揃える。体格差（子供・老人）は画像内の大きさで表す（同じキャンバスの高さで描く）
- 向き：既定では**画面の左を向いた姿**で描く（主人物は右に置かれ、左の相手と向かい合う）。右向きで揃えたなら `manifest.json` の `silFacing` を `"right"` にする
- 読み込みに失敗したファイルは自動で仮素材に戻ります

## MVP の必要枚数（1時代）

- 背景：15場所 × 昼 = 15枚（仕様の「16場所」は選択肢の数で、`不明` のときは背景を替えないため絵は不要）
- シルエット：6体型 × 5ポーズ = 30枚
- 群衆：2枚
